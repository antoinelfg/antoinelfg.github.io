Design and generate a premium personal academic website for a first-year PhD student in AI / computational research / biomedical-oriented machine learning.

This website must not look like a generic GitHub.io academic homepage. It should feel serious, elegant, memorable, modern, geometric, and visually ambitious, while still remaining credible for academic and professional audiences. The goal is to communicate that the owner is an early-career researcher with strong potential, strong technical taste, and a real design sensibility.

The website should work as a free personal website, ideally easy to adapt for GitHub Pages deployment. It should be responsive, lightweight enough to load well, and easy to maintain over time.
